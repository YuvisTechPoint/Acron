# /foundation

Goal: set up the design foundation for the whole site.
Plan first. Then:
1. Create tailwind.config and globals.css with every token from the design-system rule (colours, fluid type scale, radii, shadows, easing, container).
2. Set up fonts with next/font (Cormorant Garamond with italic, Inter), self-hosted, display swap.
3. Build primitives in /components/ui: Button (primary, secondary, ghost, dark-section variants, loading, arrow slide), Link (animated underline), Eyebrow, SectionHeading (eyebrow, serif headline with an optional italic brass word, intro), Rule (hairline with brass tick), ArchImage (arch mask with reveal), Card (spotlight hover), Input, Textarea, Select, Checkbox, Accordion, Badge, Stepper, Toast.
4. Build motion helpers: Reveal (fade-up once), LineReveal (headline), CountUp (once), Spotlight (pointer only), ReadingProgress, and a usePrefersReducedMotion hook. All must degrade to static when reduced motion is on.
5. Create a /design-system page showing every token and component in all states, plus a contrast report table generated by a script.
6. Produce a task list, plan and a walkthrough with screenshots of /design-system at 360 and 1280 px.
