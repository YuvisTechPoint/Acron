# /portal-and-admin-skin

Apply the design system to the POSH portal and the admin and organisation consoles without breaking functionality.
POSH COMPLAINANT AND RESPONDENT PORTALS: calm mode. Ivory and blue-100 surfaces, serif headings, no ornamental motion beyond a 200ms fade, no red styling (use soft amber for errors), a persistent Quick Exit button, generous spacing, one question per screen where defined, clear "what happens next" panels.
IC WORKSPACE, ORGANISATION CONSOLE, ACORN CONSOLE, ADMIN: dense, professional. White cards on ivory-50, navy sidebar with a brass active indicator, Inter 14px tables with hairline rules, status chips with icon and text, KPI tiles with a thin brass top rule, charts using a navy, blue, brass and slate palette. No grain, no oak-leaf ornament, no decorative motion except live-feed highlight.
